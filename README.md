# RAN GitHub Updater Dummy

Disposable public integration fixture for proving real WordPress Core updates
through `ran/wp-github-release-updater`.

This repository is not a production plugin and is not published to
WordPress.org. Its release ZIP and manifest intentionally exercise the updater's
public GitHub Release contract.

The `v0.2.0` release proves a native update from an installed `0.1.0` fixture.
The `v0.2.1` release verifies current-version state after the update completes.
